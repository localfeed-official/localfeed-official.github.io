대표님 쇼츠

대표님이 직접 주신 사진과 동의를 바탕으로, 대표님이 말하는 짧은 영상을 주 1편 만듭니다.

어떻게 진행되나요

  1. 대표님이 매장 사진과 기본 정보(영업시간, 가격 등)를 보내주십니다.
  2. 로컬피드가 콘텐츠를 만들어 확인 페이지로 보내드립니다.
  3. 대표님이 좋아요를 누르면 올라가고, 바꿔주세요를 누르면 고쳐서 다시 보여드립니다.
  4. 대표님이 확인하지 않은 콘텐츠는 올리지 않습니다.

틱톡 연결 안내

로컬피드는 TikTok의 공식 로그인(Login Kit)과 콘텐츠 업로드 기능(Content Posting API)을 사용합니다.

  1. 대표님이 로컬피드 연결 링크를 열고, 본인 틱톡 계정으로 직접 로그인해 권한을 허락합니다. 로컬피드는 비밀번호를 받지 않습니다.
  2. 대표님이 확인 페이지에서 승인한 영상만 대표님 틱톡의 초안(받은편지함)으로 보냅니다.
  3. 대표님이 틱톡 앱 알림을 눌러 내용을 확인하고 직접 게시합니다.
  4. 연결은 언제든 틱톡 앱의 설정에서 해제하거나, 이메일로 요청해 끊을 수 있습니다.

LocalFeed (English)

LocalFeed is a social media management service for small local shops in Korea. Shop owners send us photos and basic shop information. We create card news, captions for each channel, and short videos, and send them to the owner for approval. Nothing is published without the owner's approval.

TikTok integration. The shop owner signs in with their own TikTok account through TikTok Login Kit and grants permission. We never ask for or store passwords. Only videos the owner approved on our review page are uploaded to the owner's TikTok inbox as drafts using the Content Posting API (Upload). The owner reviews the draft in the TikTok app and posts it themselves. Owners can disconnect at any time in TikTok settings or by emailing us.
